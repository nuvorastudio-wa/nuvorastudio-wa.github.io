NuvoraCore

NuvoraCore is a private desktop tool that its owner (NuvoraStudio, an independent creator) uses to publish the videos he produces to his own YouTube channel, Nico Sin Límites.

It runs only on the owner's own computer (it is not a website and is not offered to the public). It never accesses anyone else's account.

How it uses YouTube

NuvoraCore uses the YouTube API Services.

  • The owner connects his own channel with Google sign-in (OAuth 2.0) and can disconnect it at any time.
  • Upload a finished video (videos.insert) with the title, description and privacy (private, unlisted or public) chosen by the owner.
  • Set the video's thumbnail (thumbnails.set) and captions (captions.insert).
  • Check the upload/processing status (videos.list) and make the video public at the time the owner scheduled (videos.update).
